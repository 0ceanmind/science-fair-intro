# Science Fair Intro — downloads

Download page for the Science Fair 2026 intro (Al Risala School).

The page is a single static `index.html` with its images in `assets/`.
The files it offers are attached to the [latest release](../../releases/latest):

| File | What it is |
|---|---|
| `ScienceFairIntro.exe` | Windows 10/11, portable, no install |
| `ScienceFairIntro.apk` | Android 9+, tablets and phones |
| `ScienceFairIntro.mp4` | 1080p recording of the intro |

The browser version runs at https://science-fair-intro.vercel.app
