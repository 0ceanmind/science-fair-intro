# World Science Day Intro — downloads

Download page for the World Science Day 2026 intro («اليوم العالمي للعلوم», Al Risala School): https://science-fair-downloads.vercel.app
The event was called «معرض العلوم» (Science Fair) until 2026-11-11, which is why the repository and file names still say science-fair.

The page is a single static `index.html` with its images in `assets/`.
The files it offers are attached to the [latest release](../../releases/latest) (v2.0, light 3D edition):

| File | What it is |
|---|---|
| `ScienceFairIntro.exe` | Windows 10/11, portable, no install. A dedicated GPU is recommended |
| `ScienceFairIntro.apk` | Android 9+ with an up-to-date System WebView, tablets and phones |
| `ScienceFairIntro.mp4` | 1080p recording of the browser version (61 s) |
| `ScienceFairIntro-phone.mp4` | Smaller copy of the same video for sharing by phone |

The browser version runs at https://science-fair-intro.vercel.app

The previous dark edition stays on release [v1.0](../../releases/tag/v1.0). Don't overwrite its files:
publish new builds as a new release, so the page's "previous version" links keep pointing at the dark edition.
